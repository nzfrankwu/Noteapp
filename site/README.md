# Noteapp website

The homepage and privacy policy Google needs to publish Noteapp's Google sign-in
(PHASE-6.md 6.6). Served by GitHub Pages from the `gh-pages` branch:

- https://nzfrankwu.github.io/Noteapp/
- https://nzfrankwu.github.io/Noteapp/privacy.html

`img/` holds the screenshots (WebP, 1600 px wide), taken on the emulator with made-up demo data
only (fake Canvas, a made-up lecture handout): never use screenshots of real notes or courses.

Edit here, then copy the files to the `gh-pages` branch. `logo.svg` is the same drawing as the
launcher icon (`app/src/main/res/drawable/ic_launcher_foreground.xml`).
